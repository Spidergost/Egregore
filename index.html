✨ Inspiration du jour

Chargement…

Le même tirage pour tout le monde aujourd'hui, grâce à une graine fondée sur la date. Explorer d'autres tirages.

Comment ça marche ?

Chaque tirage utilise une graine : un court code comme k4m9xq. Même graine, même résultat, pour tout le monde. Envoyez un lien à vos joueurs et ils verront exactement la même rumeur, la même auberge ou le même PNJ que vous.

Les tables sont de simples fichiers JSON dans data/ : n'importe qui peut en ajouter une sans toucher au code.
